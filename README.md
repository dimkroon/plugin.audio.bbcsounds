plugin.audio.bbcsounds
======================

A plug-in for the [Kodi media center](https://kodi.tv) that unlocks the
wonderful world of BBC Sounds for Kodi users.

This is an unofficial plug-in, not created or endorsed by the BBC.

The plugin is currently in the alpha stage. Although a few features are 
still missing, the addon should now be in a decent enough state to be tested by 
a wider audience.


### Installation

Because of the alpa stage, the addon can currently only be installed as zip 
file from this repo. 
- Click on the green button named '<> Code' on the top of this page
- Select 'Download ZIP'
- Save the zip in a folder that is accessible from Kodi.
- In Kodi, from the home page go to 'settings > Add-ons > Install from zip file'
- Select the zip file and install.
- After installation, open the add-on's settings and log in with your BBC 
  account.


### Usage
Most features should work. Just browse through the add-on to see what is 
available. An important part of the functionality is available through an 
item's context menu. Most notably, the button 'More episodes' that is 
present on many items on the website is implemented in the add-on via the 
context menu.

Likewise, functions like 'subscribe' and 'bookmark' can also be found in the 
context menu. And playable items often have extended information available 
via the context menu option 'information'.

### Issues
I'm very interested in any issues that you might find. Please open an issue 
here on GitHub, or post a message on 
the [support thread in the Kodi forum](https://forum.kodi.tv).

Please include an accurate description of the problem. Describe 
exactly what steps to make to reproduce the problem (every click from the 
home menu). And always attach a link to a 
[debug log file](https://kodi.wiki/view/Log_file).
